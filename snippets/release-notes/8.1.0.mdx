# 8.1.0 Release Notes

Release Date:  11 August 2025

Release Notes Last Updated: 22 December 2025

## Corrected Issues in Aviatrix Release 8.1.0

AVX-59298: Fixed an issue where Edge Spoke or Edge Transit Gateways deployed on Megaport Virtual Edge (MVE) with fewer than 5 VNICs failed to initialize due to cloud-init expecting 5 interfaces. The initialization process now supports deployments with fewer interfaces.
